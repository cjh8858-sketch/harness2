# 카드뉴스 템플릿 가이드

`cardnews.jpg` 레퍼런스의 표지 구성을 분석해 만든 카드뉴스 제작 가이드입니다. 사진과 문구는 레퍼런스의 것을 그대로 복제하지 말고, 주제에 맞는 이미지와 자체 콘텐츠로 교체해 사용합니다.

## 1. 레퍼런스에서 확인한 시각 구조

- **화면 비율:** 세로형 4:5에 가까운 구성. SNS 피드용 제작 시 1080 × 1350 px 권장
- **배경:** 화면 대부분을 차지하는 인물 사진. 얼굴과 시선이 제목을 방해하지 않도록 배치
- **명암:** 사진 위에 검정 계열의 어두운 그라데이션/오버레이를 두어 흰 제목을 강조
- **타이포그래피:** 큰 굵은 한글 제목과 작은 세리프형 보조 문구의 대비
- **색상:** 블랙·화이트 중심에 강한 블루를 한 가지 포인트로 사용
- **정보 위계:** 상단의 작은 카테고리/브랜드 표기 → 이미지 속 짧은 보조 문구 → 하단의 큰 메인 제목
- **인상:** 에디토리얼하고 대담하며, 한 장만 보아도 주제가 읽히는 표지 스타일

## 2. 카드뉴스 전체 디자인 규칙

### 캔버스와 안전 여백

- **기본 크기:** 1080 × 1350 px (4:5)
- **좌우 여백:** 최소 64 px 권장
- **상하 여백:** 가장자리에서 60 px 이상 확보
- 피드 미리보기에서 잘릴 수 있으므로 핵심 제목, 로고, 페이지 표시는 안전 영역 안에 둡니다.
- 인쇄물이나 다른 SNS 규격으로 변환할 때는 원본 비율을 무리하게 늘리지 말고 별도 리사이즈합니다.

### 색상과 대비

| 역할 | 레퍼런스 기반 권장 |
|---|---|
| 기본 어두운색 | 블랙 또는 매우 짙은 차콜 |
| 기본 밝은색 | 화이트 |
| 포인트 | 선명한 블루 한 가지 |
| 사진 보정 | 텍스트 뒤 영역에 어두운 반투명 오버레이/그라데이션 |

- 위 팔레트는 이 레퍼런스의 디자인 방향이며 공식 브랜드 색상은 아닙니다.
- 한 카드 안에서 포인트 컬러를 여러 개 섞기보다 한 가지를 반복해 통일감을 줍니다.
- 텍스트가 배경 사진에 묻히지 않도록 충분한 명도 대비를 확보합니다.
- 글자 뒤에 오버레이를 쓰더라도 사진의 주요 피사체가 지나치게 어둡게 뭉개지지 않도록 조절합니다.

### 타이포그래피

- **메인 제목:** 굵은 고딕 계열, 짧고 크게. 표지의 시선 집중 요소로 사용
- **보조 문구:** 작은 크기와 가벼운 웨이트로 메인 제목과 구분
- **강조 단어:** 블루 배경 박스 또는 블루 글자 등 한 가지 방법으로만 강조
- **본문:** 모바일에서 읽히는 크기로 작성하고, 한 카드에 긴 문단을 넣지 않음
- 실제 폰트명은 레퍼런스에서 확인되지 않았으므로 프로젝트 환경에서 사용 가능한 가독성 높은 폰트를 선택합니다.

## 3. 권장 카드뉴스 흐름 (6장)

주제와 매체에 따라 장수를 조절합니다. 한 장에는 핵심 메시지 하나만 둡니다.

### 1장 — 표지 / Hook

- **목표:** 무엇에 관한 콘텐츠인지 즉시 알리고 다음 장을 보게 만들기
- **배치:** 사진을 배경 전체에 깔고, 하단 또는 빈 공간에 큰 제목 배치
- **요소:** `[카테고리]`, `[짧은 문제 제기/약속]`, `[메인 제목]`, `[브랜드/계정명]`
- **문구 예시 틀:**
  - `[대상/상황]을 위한`
  - `[핵심 주제], 이렇게 시작하세요`
- 표지 제목은 핵심 단어 위주로 2~4줄 이내로 정리합니다.

### 2장 — 문제 제기 / 공감

- **목표:** 독자가 겪는 문제나 질문을 구체화
- **배치:** 짧은 헤드라인 + 한 가지 사진/그래픽 또는 큰 숫자
- **텍스트 틀:** `혹시 [구체적 상황] 때문에 고민인가요?`
- 개인을 비난하거나 불필요한 불안·공포를 조장하지 않고 사실에 기반해 표현합니다.

### 3장 — 핵심 정보 1

- **목표:** 첫 번째 해결 정보 전달
- **배치:** 큰 번호 또는 키워드 + 2~3줄 설명 + 관련 이미지/아이콘
- **텍스트 틀:** `[핵심 방법 1]` / `[왜 필요한지 한 문장]`

### 4장 — 핵심 정보 2

- **목표:** 다음 단계 또는 비교 관점 제공
- **배치:** 3장과 같은 그리드와 타이포그래피를 유지
- **텍스트 틀:** `[핵심 방법 2]` / `[실행 팁 또는 주의점]`

### 5장 — 적용 예시 / 요약

- **목표:** 앞의 정보를 실제 행동이나 예시로 연결
- **배치:** 전후 비교, 체크리스트, 단계 흐름 중 하나만 선택
- **텍스트 틀:** `[예시 또는 체크 항목]`
- 수치·인용·사례를 제시할 경우 출처와 기준 시점을 확인합니다.

### 6장 — 결론 / CTA

- **목표:** 핵심을 다시 요약하고 다음 행동 안내
- **배치:** 가장 중요한 한 문장 + 저장/문의/링크 등 CTA + 계정명
- **텍스트 틀:** `오늘의 핵심: [한 문장]` / `저장하고 필요할 때 확인하세요`
- 실제 제공하지 않는 서비스를 약속하거나 근거 없는 성과를 보장하지 않습니다.

## 5. 이미지와 문구 배치 체크

- 표지 사진은 주제와 관련 있고, 제목이 놓일 여백이 있는 이미지를 선택합니다.
- 인물 사진을 쓸 때 얼굴이나 중요한 동작 위에 제목을 겹치지 않습니다.
- 모든 카드에 같은 폰트, 여백, 페이지 표기 위치를 유지합니다.
- 본문은 한 장당 제목 1개와 핵심 내용 1개를 기본으로 합니다.
- 강조 효과(블루 박스, 밑줄, 큰 따옴표 등)는 한 카드에서 1~2개 이내로 제한합니다.
- 표지의 어두운 사진 스타일을 모든 본문에 강제하지 않습니다. 본문은 정보 가독성에 맞춰 밝은 바탕을 써도 됩니다.
- 이미지 내에 이미 글자가 많은 경우 카드뉴스 문구를 줄여 시각적 혼잡을 방지합니다.
- 외부 이미지·인물·상표를 사용할 때 사용 허가와 출처 표기 조건을 확인합니다.

## 6. 게시 전 검수

- [ ] 첫 장만 보아도 주제와 독자가 분명한가?
- [ ] 카드 순서가 문제 제기 → 정보 → 예시 → 행동으로 자연스럽게 이어지는가?
- [ ] 모바일 크기로 보아도 제목과 본문이 읽히는가?
- [ ] 사진과 글자의 대비가 충분하고, 텍스트가 안전 여백 안에 있는가?
- [ ] 띄어쓰기·맞춤법·숫자·링크·계정명이 정확한가?
- [ ] 정보, 통계, 인용에 확인 가능한 출처가 있는가?
- [ ] 사진과 그래픽의 저작권·초상권을 확인했는가?
- [ ] 계정 그리드 미리보기에서도 표지의 핵심 제목이 잘리지 않는가?
