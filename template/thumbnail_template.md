# YouTube 썸네일 템플릿

`thumb_nail (1).jpg`, `(6).jpg`, `(7).jpg`, `(8).jpg`를 참고해 정리한 썸네일 제작 가이드입니다. 원본 이미지의 문구·로고·사진을 그대로 재사용하지 말고, 영상 주제와 사용 권한에 맞는 콘텐츠로 교체하세요.

## 1. 레퍼런스 관찰 요약

- **화면 비율:** 가로형 16:9. YouTube 썸네일 권장 제작 크기 1280 × 720 px
- **반복되는 프레임:** 청록색 테두리와 어두운 배경을 조합한 강한 외곽 구조
- **정보 위계:** 상단의 시리즈/버전 배지 → 중앙의 영상 이미지·화면 캡처 → 하단의 매우 큰 제목
- **제목 스타일:** 굵은 흰색 한글, 검정 외곽선 또는 그림자. 핵심 단어는 청록색으로 강조
- **보조 요소:** 화살표, 손그림 메모, 서비스/도구 로고, 결과 화면 캡처
- **대안 표지:** 첫 번째 레퍼런스는 밝은 바탕에 로고 비교와 외곽선 제목을 배치한 정보형 구성
- **전체 인상:** 튜토리얼·도구 소개에 적합한 선명하고 실용적인 스타일. 여러 요소가 강하게 경쟁할 수 있어 메시지와 장식의 우선순위를 조절하는 것이 중요

## 2. 기본 캔버스와 디자인 규칙

### 캔버스

- **기본:** 1280 × 720 px, 16:9
- **안전 영역:** 제목과 로고는 화면 가장자리에서 최소 48 px 안쪽에 둡니다.
- **축소 검수:** 썸네일을 실제 검색/추천 화면 크기로 줄여 제목이 읽히는지 확인합니다.
- **중요 요소:** 영상의 주인공, 제품, 핵심 UI, 제목을 화면 축소 후에도 알아볼 수 있도록 배치합니다.

### 색상

| 역할 | 권장 표현 |
|---|---|
| 기본 배경 | 블랙/차콜 또는 영상 주제와 맞는 어두운 이미지 |
| 프레임/포인트 | 청록·시안 계열 |
| 제목 | 화이트 + 검정 외곽선/그림자 |
| 핵심 단어 | 청록, 또는 제한적으로 오렌지 |
| 보조 텍스트 | 화이트 또는 밝은 중립색 |

- 이 색 구성은 제공된 썸네일 이미지의 시각적 관찰을 바탕으로 한 제안이며 공식 브랜드 컬러 규정은 아닙니다.
- 한 썸네일에서는 강조 색을 1~2개로 제한합니다.
- 이미지가 어두운 경우 제목은 밝게, 이미지가 밝은 경우 제목 뒤에 어두운 패널이나 외곽선을 사용합니다.

### 타이포그래피와 문구

- 큰 제목은 굵고 선명한 고딕 계열로 구성합니다.
- 제목은 핵심 메시지 한 가지를 중심으로 1~2줄로 제한합니다.
- 핵심 키워드만 색상 또는 크기로 강조하고 모든 단어에 효과를 주지 않습니다.
- 보조 문구/배지는 제목보다 작게 두며, 영상 내용을 보충하는 정보만 표시합니다.
- 제목은 실제 영상 내용과 일치하게 작성하고 과장되거나 오해를 부르는 표현을 피합니다.

## 3. 썸네일 레이아웃 템플릿

### A. 튜토리얼·도구 소개형

**참고:** `thumb_nail (6).jpg`, `thumb_nail (7).jpg`, `thumb_nail (8).jpg`

```text
┌──────────────────────────────────────────┐
│ [영상 캡처/인물/제품]       [시리즈 배지] │
│                            [짧은 메모]   │
│                                          │
│ [큰 제목: 핵심 문장]                     │
│ [청록 강조 키워드] [나머지 제목]         │
└──────────────────────────────────────────┘
```

- 왼쪽 또는 중앙에는 결과 화면, 도구 UI, 제품, 진행자 중 하나를 크게 배치합니다.
- 반대쪽의 어두운 영역에는 배지와 짧은 보조 정보를 둡니다.
- 아래쪽 제목 영역은 넓게 확보하고 이미지의 핵심 피사체를 가리지 않도록 합니다.
- 화살표/손글씨는 실제로 가리키거나 설명할 대상이 있을 때만 사용합니다.
- 바깥 청록 프레임은 선택 요소입니다. 내부 이미지까지 복잡하면 프레임 두께를 줄이거나 생략합니다.

### B. 비교·선택 가이드형

**참고:** `thumb_nail (1).jpg`

```text
┌──────────────────────────────────────────┐
│ [짧은 약속/카테고리 배지]                │
│                                          │
│ [도구/대상 A]  VS  [도구/대상 B]         │
│                                          │
│ [질문 또는 비교 주제]                    │
│ [결론/핵심 결과]                         │
└──────────────────────────────────────────┘
```

- 비교 대상은 2~3개 안에서 명확히 보여줍니다.
- 각 로고/제품의 크기와 시각적 무게를 비슷하게 조정합니다.
- 하단 제목에는 영상의 비교 기준 또는 결론을 짧게 적습니다.
- 실제 비교 결과를 단정할 때는 영상에서 검증 가능한 근거가 있어야 합니다.

### C. 신제품·업데이트 소식형

```text
┌──────────────────────────────────────────┐
│ [제품/화면 대표 이미지]      [NEW/버전]  │
│                                          │
│ [한눈에 보이는 변화/장점]                │
│ [제품명 또는 업데이트 키워드]            │
└──────────────────────────────────────────┘
```

- 배지는 실제 업데이트/출시 정보가 확인된 경우에만 사용합니다.
- 연도·버전·출시 여부는 현재 영상 내용과 일치하는지 확인합니다.
- 썸네일 제작 후 정보가 바뀔 수 있는 가격·일정은 신중히 넣습니다.

## 4. 문구 작성 템플릿

아래 문구는 작성 구조 예시입니다. 영상에서 실제로 다루는 내용에 맞춰 채웁니다.

```text
시리즈/배지: [초보자용 / 2026 업데이트 / 한 번에 정리]
보조 메모: [짧은 맥락 또는 사용 조건]
메인 제목 1행: [시청자가 얻을 결과 또는 핵심 질문]
메인 제목 2행: [핵심 도구/방법/대상]
강조 키워드: [한두 단어]
시각 요소: [인물/제품/UI/전후 화면 중 하나]
```

문구 검토:

- 영상의 핵심 가치가 제목만으로 전달되는가?
- 모바일 크기로 줄였을 때 핵심 단어가 남는가?
- 제목이 실제 영상 내용과 과장 없이 일치하는가?
- 영상 제목과 썸네일 문구가 같은 말을 반복하지 않고 서로 보완하는가?

## 5. 제작 순서

1. 영상의 핵심 주제와 시청자 효용을 한 문장으로 정리합니다.
2. 인물·제품·UI·결과 화면 중 썸네일의 주인공을 하나 선택합니다.
3. 썸네일 레이아웃(A/B/C) 중 영상 성격에 맞는 구조를 고릅니다.
4. 핵심 문구를 1~2줄로 줄이고 강조 키워드를 정합니다.
5. 글자와 배경의 대비를 맞추고, 불필요한 효과와 장식을 제거합니다.
6. 실제 축소 화면에서 가독성·표정·제품 식별성을 확인합니다.
7. 영상 제목과 함께 보았을 때 오해나 중복이 없는지 검수합니다.
