# Qoomee Studio 포트폴리오 PPT 템플릿

이 템플릿은 같은 폴더의 `portfolio (1).jpg`, `(2).jpg`, `(3).jpg`, `(8).jpg`, `(9).jpg`, `(10).jpg`, `(15).jpg` 레퍼런스를 확인해 구성했습니다. 대괄호 안의 안내 문구를 실제 프로젝트 정보와 이미지로 교체해 사용하세요. 샘플에 보이는 프로젝트명·고객명·성과를 다른 프로젝트에 그대로 전용하지 않습니다.

## 1. 기본 슬라이드 스타일

- **화면 비율:** 와이드 16:9
- **배경:** 화이트 중심, 프로젝트 결과물의 색상과 사진을 돋보이게 구성
- **헤더:** 왼쪽에 큰 분야명, 오른쪽에 `qoomee studio` 로고, 아래쪽에 짙은 네이비 가로 구분선
- **색상:** 레퍼런스에서 반복되는 짙은 네이비(근사 `#1C275F`)를 기본 제목·구분선에 사용하고, 청록/블루는 번호·보조 구분선 등에 제한적으로 사용
- **프로젝트 색상:** 패키지·포스터·브랜드의 고유 팔레트를 보존하며 전체 PPT의 포인트 컬러로 강제 통일하지 않음
- **타이포그래피:** 큰 굵은 산세리프 제목, 읽기 쉬운 산세리프 설명. 폰트명과 색상값은 제공된 이미지에서 추정한 참고치이며 공식 CI 규정이 아님
- **레이아웃:** 좌우 여백과 이미지 간격을 통일하고, 페이지마다 중심 메시지를 하나로 제한
- **이미지:** 대표 결과물을 크게, 디테일/응용 컷은 작은 보조 이미지로 배치. 실제 결과물·목업·시안은 캡션으로 구분
- **로고:** `logo.jpg`가 같은 폴더에 있으면 비율을 유지해 사용하고, 원본 로고 파일이 별도로 있으면 원본 우선

## 2. 권장 PPT 구성 (10장)

### 01. 표지 — PORTFOLIO

**레이아웃**
- 흰 배경 또는 대표 프로젝트 이미지를 활용한 단순한 표지
- `qoomee studio` 로고와 `PORTFOLIO` 타이틀
- 하단에 `[소개 연도]` 또는 `[제안 대상]`

**텍스트**
```text
QOOMEE STUDIO
PORTFOLIO
[브랜드·패키지·로컬 디자인]
[연도 / 제안 대상]
```

### 02. 스튜디오 소개 — ABOUT US

**레이아웃:** 한쪽에 소개 문장과 서비스 키워드, 반대편에 대표 결과물 또는 작업 현장 사진.

**초안 문구(공개 소개 기반):**
```text
로컬제품 전문 에이전시
브랜딩 · 패키지 · 세일즈 · 로컬 디자인

[스튜디오가 해결하는 고객 과제와 작업 방식 2~3문장]
```

### 03. 서비스 유형 — SERVICE TYPE

**레이아웃:** `portfolio (1).jpg`의 상단 헤더와 하단 결과물 배열을 참고합니다. 서비스명과 짧은 설명을 위에 놓고, 대표 작업 이미지를 한 줄 또는 그리드로 배치합니다.

```text
01 브랜드 아이덴티티 / 로고
02 제품 패키지 / 상세페이지
03 로컬 브랜딩 / 포스터
04 이커머스 / 홍보마케팅
05 캐릭터·콘텐츠 / 영상
```

필요한 분야만 남기고, 실제 제공 서비스와 맞지 않는 항목은 삭제합니다.

### 04. 팀의 강점 — MEET OUR TEAM

**레퍼런스:** `portfolio (3).jpg`

**레이아웃:** 3열. 번호와 짧은 제목, 관련 현장 사진, 한두 문장 설명 순서로 구성합니다. 열 사이에는 가는 청록 또는 블루 구분선을 사용할 수 있습니다.

```text
01 [실무 경험/전문 영역]
[근거가 되는 프로젝트 경험 또는 현장 사진]
[확인 가능한 경험 설명]

02 [고객 문제를 이해하는 방식]
[관련 사례 이미지]
[고객의 문제와 요구를 디자인에 반영하는 방식]

03 [협업/실행 방식]
[협업 현장 또는 결과물]
[기획부터 결과 전달까지의 실제 업무 방식]
```

### 05. 프로젝트 목차 — SELECTED WORK

**레이아웃:** 대표 작업 3~6개를 카드형 썸네일로 배열합니다.

| 프로젝트 | 분야 | 대표 이미지 |
|---|---|---|
| [프로젝트명] | [브랜딩/패키지/마케팅 등] | [이미지 삽입] |
| [프로젝트명] | [분야] | [이미지 삽입] |
| [프로젝트명] | [분야] | [이미지 삽입] |

고객사명, 제작 연도, 수행 범위는 확인된 정보만 표기합니다.

### 06. 제품 패키지 사례 — PRODUCT PACKAGE

**레퍼런스:** `portfolio (1).jpg`

**레이아웃**
- 상단: `SERVICE TYPE`, 로고, 프로젝트명, 컨셉 설명
- 하단: 패키지 대표 컷 1개를 크게 배치하고 정면·측면·개별 제품 컷을 보조 배치
- 각 이미지에 `[패키지 전면]`, `[단품 적용]`, `[세트 구성]` 등 짧은 캡션 추가

**본문 블록**
```text
프로젝트명: [제품/브랜드]
디자인 방향: [제품 특성과 타깃에 맞춘 핵심 컨셉]
수행 범위: [브랜드/패키지/목업 등 실제 범위]
```

### 07. 이커머스·홍보마케팅 사례

**레퍼런스:** `portfolio (9).jpg`, `portfolio (10).jpg`

**레이아웃**
- 쇼핑몰 메인 화면과 상품 상세 화면을 좌우로 나란히 배치
- 제품 이미지 또는 상세 페이지 핵심 부분을 하단에 보조로 배열
- 화면 전체의 글자가 작아질 경우 전체 축소 대신 핵심 화면을 크롭해 확대

**캡션 예시**
```text
[채널/브랜드] 온라인 스토어 메인
[상품명] 상세페이지 / 제품 콘텐츠
수행 범위: [확인된 작업 범위]
```

가격·리뷰·판매량·혜택 등 변동 정보는 발표 시점에 확인하고, 최신성을 보장할 수 없으면 흐리게 처리하거나 제외합니다. 성과 수치는 출처와 측정 시점을 함께 씁니다.

### 08. 로컬 브랜딩·포스터 사례

**레퍼런스:** `portfolio (15).jpg`

**레이아웃**
- 상단: 프로젝트 제목과 기획 의도
- 한쪽에는 대표 포스터/키 비주얼을 크게, 다른 쪽에는 응용 포스터·정보 그래픽을 1~2개 배치
- 세로형 인쇄물은 비율을 유지해 보여주고, 세부 정보는 별도 확대 컷으로 보완

**본문 블록**
```text
프로젝트명: [지역/행사/문화 프로젝트]
기획 의도: [지역 또는 프로그램의 어떤 특성을 표현했는지]
적용 매체: [포스터/인쇄물/SNS 등 실제 제작물]
```

샘플처럼 강한 컬러와 캐릭터를 쓰는 경우에도 프로젝트의 기획 주제와 정보 위계에 맞게 적용합니다.

### 09. 프로젝트 진행 방식 — PROCESS

**레이아웃:** 4단계 흐름도 또는 가로 타임라인.

```text
01 목표·자료 확인
02 콘셉트·디자인 방향 설정
03 디자인 및 콘텐츠 제작
04 적용물 검수·전달
```

각 단계의 설명은 실제 스튜디오 프로세스에 맞게 고칩니다. 수정 횟수·일정·납품 범위를 확정 정보처럼 쓰기 전에는 내부 기준을 확인합니다.

**레이아웃:** 넓은 여백, 짧은 마무리 문장, 로고, 최신 연락처·웹/SNS 링크.

```text
함께 만들 다음 로컬 브랜드 이야기를 기다립니다.
[이메일]
[포트폴리오 웹사이트]

```

연락처와 링크가 공개 가능한 최신 정보인지 발표 전에 확인합니다.
